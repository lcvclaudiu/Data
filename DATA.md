# Data layout

## `data/diagnostics`

This directory contains the JSON output from overlap checks, MBAR reconstruction, and leave-one-window-out diagnostics. File names identify the temperature tag and lattice size.

The temperature tags used in the archived files are:

- `T0038`: `T/J = 0.0038`
- `PUB_T0050`: `T/J = 0.0050`
- `PUB_T0060`: `T/J = 0.0060`
- `T001`: `T/J = 0.0100`

## `data/processed`

This directory contains the tabular output produced during publication postprocessing. The main file families are:

- `*_summary.dat`: central estimates and bootstrap intervals;
- `*_bootstrap_samples.dat`: bootstrap draws used in uncertainty propagation;
- `*_distribution_full.dat`: reconstructed equal-weight distributions;
- `*_distribution_bootstrap.dat`: uncertainty information for those distributions;
- `*_trajectory_autocorrelation.dat`: trajectory-level correlation estimates;
- `*_adjacent_overlap.dat`: neighboring-window overlap diagnostics;
- `*_LOO.dat`: leave-one-window-out checks;
- `*_mbar_state_neff.dat` and `*_replica_mbar.dat`: MBAR diagnostics;
- `*_bootstrap_metadata.json`: settings and bookkeeping for the bootstrap runs.

Files carrying the `BF10` tag repeat the uncertainty analysis using the longer block-length sensitivity setting.

## Raw trajectories

The `.npz` production trajectories are not included in this archive. The postprocessing scripts expect them below `runs/` when the analysis is repeated from the sampling level. If the complete raw data are deposited separately, their archival record should be linked from the paper and from this repository.

## L=3 validation

The exhaustive small-system check is generated by `validate_L3_end_to_end.py`; no separate `exact_L3_validation.tsv` file is required. `validation/L3_terminal_results.txt` preserves the numerical reference values from the original interactive run. A fresh run writes `L3_validation_report.json` to the requested output directory.
